# Requirement E - Model Evaluation

Evaluation used the untouched 200-review testing partition produced by the stratified 80/20 split, which contains 100 positive and 100 negative reviews. The trained TF-IDF and Logistic Regression Pipeline generated predictions for this holdout data, after which accuracy, positive-class precision, recall, F1-score, and a confusion matrix were calculated. Accuracy reports the proportion of all correct predictions, whereas precision measures the correctness of positive predictions, recall measures the proportion of actual positive reviews identified, and F1-score balances positive-class precision and recall. Reporting these measures alongside the confusion matrix provides a more complete view than accuracy alone because it exposes the types of classification errors. This multi-metric approach is consistent with recent sentiment-analysis research that evaluates classifiers using accuracy, precision, recall, F1-score, and confusion-matrix outputs (Deshpande et al., 2025; Srianan et al., 2025).

The evaluated baseline achieved 88.00% accuracy, correctly classifying 176 of 200 held-out reviews. Positive-class precision was 87.25%, meaning that approximately 87% of reviews predicted as positive were actually positive. Positive-class recall was 89.00%, so the model identified 89 of the 100 actual positive reviews in the test partition. The F1-score was 88.12%, reflecting the balance between these precision and recall values. These values were calculated by the program and saved with the test-partition results, rather than being entered manually. On this specific held-out split, the baseline demonstrates strong initial classification performance while leaving room for later optimization; the result should not be generalized beyond this 1,000-review corpus or treated as a comparison with results from other datasets.

The confusion matrix contains 87 true negatives, 13 false positives, 11 false negatives, and 89 true positives. Therefore, 87 negative reviews and 89 positive reviews were classified correctly; 13 negative reviews were incorrectly predicted as positive, while 11 positive reviews were incorrectly predicted as negative. The error balance shows slightly more false positives than false negatives. The evaluation is limited to one fixed train/test split and is specific to the processed restaurant-review corpus. No hyperparameter tuning or alternate-algorithm comparison has been completed in this project, so these artifacts establish a baseline rather than an optimized result. Requirement F will address optimization separately without changing these baseline evaluation artifacts.
