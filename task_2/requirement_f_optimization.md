# Requirement F - NLP Model Optimization

Optimization preserved the original stratified 80/20 split and used only the 800 training observations for parameter selection. A `StratifiedKFold` procedure with five shuffled folds and `random_state=42` preserved the positive and negative distribution within each training-data fold. `GridSearchCV` optimized F1-score across 16 joint TF-IDF and Logistic Regression configurations, producing 80 cross-validation fits. The search retained Logistic Regression as the model family while varying `classifier__C`, which controls regularization inversely; `tfidf__ngram_range`, which compared unigrams with unigrams plus bigrams; and `tfidf__sublinear_tf`, which compared ordinary and sublinear term-frequency scaling. The 200-review test partition was excluded from GridSearchCV so it could remain an independent holdout for the selected estimator. This systematic use of cross-validation and grid search is appropriate for sentiment-model parameter selection because outcomes depend on the model and data configuration (Brandão et al., 2025; Emphan et al., 2025).

The training-only search selected `classifier__C=4.0`, `tfidf__ngram_range=(1, 1)`, and `tfidf__sublinear_tf=False`, with a best mean cross-validation F1-score of 0.8650. On the unchanged test partition, the baseline achieved accuracy 88.00%, precision 87.25%, recall 89.00%, and F1-score 88.12%; the selected estimator achieved 88.50%, 87.38%, 90.00%, and 88.67%, respectively. The resulting changes were +0.50 percentage points in accuracy, +0.12 percentage points in precision, +1.00 percentage point in recall, and +0.55 percentage points in F1-score. The optimized confusion matrix retained 87 true negatives and 13 false positives, while reducing false negatives from 11 to 10 and increasing true positives from 89 to 90. Thus, the optimized model identified one additional positive review, representing a measurable but limited improvement rather than a claim of statistical significance.

The results also show that the more complex bigram feature option and sublinear term-frequency scaling did not necessarily outperform the simpler unigram representation for this corpus. Hyperparameter tuning provides a systematic basis for selecting among the configured candidates, but it cannot guarantee a dramatic improvement on an independent test set. Both the cross-validation score and optimized holdout result remain specific to this 1,000-review restaurant corpus; larger datasets, different preprocessing, or other model families could yield different selections and results. The test partition was not used to select GridSearchCV parameters, and the baseline metrics, report, and confusion matrix remain retained separately from optimized artifacts. Preserving both sets of generated files and the full grid-search results supports traceability of the modest optimization outcome without asserting that `C=4.0` is universally optimal.
